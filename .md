# Projeto: Bíblia Interlinear & Comparativa (DuckDB + Python)

## 📌 1. Visão Geral e Objetivo
O objetivo principal deste projeto é desenvolver uma aplicação de **Bíblia Interlinear e Comparativa** focada em estudo profundo das Escrituras, alta performance local e 100% de conformidade com direitos autorais.

A aplicação permite ao usuário:
1. **Comparar Traduções em Português:** Alternar entre a *Bíblia Livre (CC BY-SA 4.0)*, *Tradução Brasileira (1917)* e *Almeida (1911)*.
2. **Análise de Textos Originais:** Navegar palavra por palavra no Antigo Testamento em Hebraico/Aramaico (*WLC* / *OSHB*) e no Novo Testamento em Grego (*SBLGNT* / *Textus Receptus*).
3. **Léxico de Strong em Português:** Consultar a morfologia, lema, transliteração, pronúncia fonética e definição detalhada em português de cada palavra original via Código Strong (`H` para Hebraico, `G` para Grego).
4. **Tradução Literal Alinhada:** Exibir a tradução literal palavra por palavra paralela ao texto original.
5. **Comentários Bíblicos:** Comentários de reformadores referenteas aos livros, capítulos e versículos, disponíveis online (principalmente no site da CCEL), traduzidos para o pt-BR. Como uma Bíblia de estudo online.

## 🏗️ 2. Arquitetura Tecnológica

### Tech Stack
* **Banco de Dados:** [DuckDB](https://duckdb.org/) (Engine SQL analítica, leve e embarcada em arquivo local `.db`).
* **Linguagem para ETL e Scripts:** Python 3 (gerenciamento de conexões, limpeza de JSON/XML e carga em batch no DuckDB).
* **Interface (Futura):** App mobile/desktop (Flutter / React Native) com consultas otimizadas ao banco local.

### Esquema de ID Determinístico para Versículos
Para eliminar lookups custosos e simplificar relacionamentos entre manuscritos e traduções, utiliza-se a seguinte convenção matemática para a chave primária `verse_id`:

$$\text{verse\_id} = (\text{book\_id} \times 1.000.000) + (\text{chapter} \times 1.000) + \text{verse}$$

* **Exemplo Gênesis 1:1:** `1 * 1000000 + 1 * 1000 + 1` = `1001001`
* **Exemplo João 1:1:** `43 * 1000000 + 1 * 1000 + 1` = `43001001`

## 🗄️ 3. Estrutura do Banco de Dados (`schema.sql`)

O banco de dados relacional é composto por 7 tabelas principais:
* `books`: Cadastro dos 66 livros da Bíblia canônica (código, nome, testamento e ordem).
* `verses`: Tabela âncora canônica contendo a lista de todos os versículos bíblicos.
* `translations`: Cadastro das versões em português e licenças de uso.
* `verse_texts`: Texto corrido em português para cada versão/traduzida.
* `source_texts`: Cadastro dos manuscritos de origem (WLC, OSHB, SBLGNT, TR).
* `original_tokens`: Tabela interlinear palavra por palavra (texto com acentos, lema, morfologia, Strong ID e tradução literal).
* `strong_dictionary`: Léxico de Strong completo traduzido para o português.
